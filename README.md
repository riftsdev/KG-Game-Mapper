# KG Game Mapper v0.1

Editor nativo SwiftUI para configurar HUD, teclas e perfis em jogos compatíveis.

## Compilação
Abra Actions > Build iOS (unsigned) > Run workflow. Baixe o artefato IPA após uma compilação bem-sucedida.

O IPA produzido **não é assinado** e requer assinatura/provisionamento válido para instalar. Compatibilidade com AltStore Classic não é garantida.

## Limitações
O iOS não permite que apps comuns injetem toques ou exibam HUD global sobre jogos externos como Free Fire. O mapeamento funciona dentro deste app ou de jogos que integrem explicitamente sua lógica.
